# C08_03_run_hall — 복도에서 뛰기 (예시)

| 필드 | 내용 |
| --- | --- |
| ID | C08_03_run_hall |
| 유형 | 함정 |
| 맵 | Map005 2층 복도 |
| 발생 조건 | 스위치 `S010 복도 진입` ON, 플레이어가 대시 상태 |
| 관련 수칙 | R01 (복도에서는 절대 뛰지 마라) |
| 플레이어 행동 | 걷기 / 뛰기 / 사물함에 숨기 |
| 결과 | 걷기 → 아무 일 없음 · 뛰기 → 학생주임 등장, 10초 추격 · 추격 중 사물함에 숨기 → 생존, 신뢰도(다인) +1 · 잡힘 → 사망 도감 D02 |
| 사망 시 힌트 | "복도에 붙은 수칙을 다시 읽어 보자." |
| 연출 | 대시 시작 1초 뒤 형광등이 차례로 꺼짐, 멀리서 호루라기 소리 |
| 대사 | 다인: "뛰면 안 된다고 써 있었잖아!" |
