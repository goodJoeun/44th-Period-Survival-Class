## 게임 개요

| 항목 | 내용 |
| --- | --- |
| 가제 | 수업은 끝나지 않는다 (검토 필요) |

## 세계관과 설정

7교시 종이 울린 뒤 학교가 '다른 곳'으로 넘어가고, 종이 울릴 때마다 교시가 하나씩 늘어납니다.
마지막 교시가 끝나기 전에 나가지 못하면 영원히 갇힙니다.

- **무대**: 본관 3층, 별관(과학실·음악실), 체육관, 옥상, 지하 보일러실
- **생존 수칙**: 10년 전 생존자가 남긴 낙서 같은 규칙. 일부는 찢어져 있고, 일부는 거짓
- **'선생님'들**: 교과목마다 다른 규칙으로 학생을 쫓는 괴물
- **시간**: 교시마다 타이머, 종이 울리면 맵 구조 일부가 바뀜

| 인물 (가명) | 역할 |
| --- | --- |
| 서지훈 (주인공) | 평범한 2학년. 그날 교실에서 자다 남게 됨 |
| 한다인 | 수칙을 해석하는 전교 1등. 수칙을 너무 믿는 것이 약점 |
| 강태민 | 운동부. 수칙을 무시하고 모두를 이끌려 함 |
| 윤하늘 | 말수가 적은 전학생. 수칙을 남긴 사람과 연결됨 |
| 박서연 | 신망이 두터운 반장. 결정을 미루다 모두를 위험에 빠뜨릴 수 있음 |

## 핵심 시스템

| 시스템 | 내용 | 구현 |
| --- | --- | --- |
| 수칙 수첩 | 수칙 쪽지를 모아 읽음. 찢어진 쪽지는 두 조각을 맞춰야 완성 | 아이템 + 공통 이벤트 |
| 규칙 위반 즉사 | 수칙을 어기면 '선생님' 등장 또는 즉사. 사망 도감에 기록 | 스위치 + 게임오버 커스터마이즈 |
| 추격 | 특정 구간에서 선생님이 쫓아옴. 사물함·화장실에 숨기 | 이벤트 이동 루트 + 추격 플러그인 |
| 교시 타이머 | 교시마다 제한 시간. 종이 울리면 맵 일부가 바뀜 | 타이머 + 맵 교체 |
| 동료 신뢰도 | 친구의 말과 수칙 중 무엇을 따를지 선택. 엔딩과 생존자 결정 | 변수 |
| 퍼즐 | 교과목 테마 퍼즐 (시약 조합, 계이름 자물쇠, 시간표 암호) | 숫자 입력 + 스위치 |

설계 원칙: 거짓 수칙은 반드시 다른 수칙이나 환경 단서와 모순되게 만들어, 죽지 않고도 추리로 가려낼 수 있게 합니다.
즉사 함정 직전에는 자동 저장을 두어 죽음이 벌이 아닌 '배움'이 되게 합니다.

## 챕터 구성

| 챕터 | 구역 | 괴물 | 배우는 것 | 사건 |
| --- | --- | --- | --- | --- |
| 8교시 (프롤로그) | 2학년 교실·복도 | 학생주임 (뛰면 나타남) | 수칙 수첩, 추격과 숨기 | 담임이 교실 밖으로 나간 뒤 돌아오지 않음 |
| 9교시 | 과학실 | 화학 선생 (냄새에 반응) | 퍼즐, 거짓 수칙 | 동료들과 합류 |
| 10교시 | 음악실·방송실 | 음악 선생 (소리에 반응) | 소리 내지 않기, 신뢰도 선택 | 첫 동료 사망 가능 구간 |
| 11교시 | 체육관 | 체육 선생 (멈추면 죽음) | 타이머 압박 | 동료끼리 갈등, 팀 분열 |
| 12교시 | 교무실·도서관 | 교감 (수칙을 바꿈) | 10년 전 생존자의 진실 | 수칙을 남긴 사람의 정체 |
| 13교시 (최종) | 옥상 또는 지하 보일러실 | 끝나지 않는 종 | 수칙 종합 | 탈출 경로 선택 |

챕터 사이에는 쉬는 시간(보건실)을 두어 동료와 대화하고 신뢰도를 쌓거나 잃게 합니다.
