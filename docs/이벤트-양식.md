# 이벤트 작성 양식

괴물 등장, 함정, 퍼즐, 대화, 컷신까지 모든 장면을 같은 양식으로 작성합니다.
새 이벤트는 `design/events/` 아래에 `{챕터}_{순번}_{이름}.md`로 만들고, 아래 표를 복사해 채웁니다.

| 필드 | 설명 | 예시 |
| --- | --- | --- |
| ID | `C{교시}_{순번}_{이름}` | `C08_03_run_hall` |
| 유형 | 탐색 / 수칙 쪽지 / 함정 / 추격 / 퍼즐 / 대화 / 컷신 / 쉬는 시간 | 함정 |
| 맵 | RPG Maker 맵 번호와 이름 | Map005 2층 복도 |
| 발생 조건 | 스위치·변수·아이템·교시 타이머 | 스위치 `S010 복도 진입` ON |
| 관련 수칙 | 이 이벤트와 연결된 수칙 ID | R01 |
| 플레이어 행동 | 고를 수 있는 행동 | 걷기 / 뛰기 / 사물함에 숨기 |
| 결과 | 행동별 결과, 바뀌는 스위치·변수, 신뢰도 변화 | 뛰기 → 학생주임 추격, 사망 도감 D02 |
| 사망 시 힌트 | 게임오버 화면에 보여줄 한 줄 | "복도에 붙은 수칙을 다시 읽어 보자." |
| 연출 | BGM, 효과음, 화면 흔들림, 조명 | 형광등 깜빡임, 발소리 정지 |
| 대사 | 등장인물별 대사 | 다인: "뛰면 안 된다고 써 있었잖아!" |

## 스위치·변수 번호 규칙

| 범위 | 용도 |
| --- | --- |
| 스위치 001~099 | 진행 플래그 (챕터 시작·종료) |
| 스위치 100~299 | 수칙 쪽지 획득 (R01 = 101) |
| 스위치 300~499 | 맵별 이벤트 상태 |
| 변수 001~010 | 교시 번호, 타이머, 생존자 수 |
| 변수 011~015 | 동료별 신뢰도 (다인, 태민, 하늘, 서연) |
| 변수 016~050 | 퍼즐 진행 상태 |
