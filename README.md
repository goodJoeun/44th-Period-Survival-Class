# 44교시 공포 탈출 게임 (가제)

이상현상에 삼켜져 미로가 된 고등학교에서, 찢어진 '생존 수칙'을 모아 해석하며 친구들과 탈출하는
2D 탑다운 공포 어드벤처입니다. 쯔꾸르(RPG Maker MZ)로 제작합니다.

> **비공식 팬게임 안내**
> 이 프로젝트는 비영리 팬 창작물입니다. 원작 《44교시 생존수업》(상C, 네이버웹툰)의 모든 권리는
> 원작자와 네이버웹툰에 있습니다. 판매·후원·광고 등 어떤 형태의 수익도 얻지 않으며,
> 권리자의 요청이 있으면 즉시 배포를 중단합니다.

## 폴더 구조

| 경로 | 내용 |
| --- | --- |
| `docs/` | 기획 문서 (기획안, 수칙 목록, 이벤트 작성 양식, 로드맵) |
| `design/` | 챕터·이벤트 설계 데이터 |
| `game/` | RPG Maker MZ 프로젝트 (에디터로 생성, 아래 참고) |
| `art/source/` | 도트·일러스트 원본 (.aseprite, .psd 등) |
| `art/export/` | 게임에 넣기 전 내보낸 이미지 |
| `audio/source/` | 효과음·BGM 원본 |
| `tools/` | 보조 스크립트 |

## 시작하기

1. RPG Maker MZ를 실행하고 **파일 → 새 프로젝트**를 선택합니다.
2. 폴더 이름은 `game`, 위치는 `D:\44gyosi-escape`로 지정합니다.
3. 프로젝트가 생기면 아래처럼 커밋합니다.

```bash
git add game
git commit -m "RPG Maker MZ 프로젝트 생성"
```

## 개발 규칙

- 브랜치: `main`은 항상 실행 가능한 상태로 유지하고, 작업은 `feature/챕터-기능` 브랜치에서 합니다.
- 에디터를 연 채로 `git pull`이나 브랜치 전환을 하지 않습니다. 에디터가 데이터 파일을 덮어쓸 수 있습니다.
- `game/data/Map***.json`은 한 사람이 한 맵씩 맡아 충돌을 줄입니다.
- 세이브 파일과 배포 빌드는 저장소에 올리지 않습니다 (`.gitignore` 참고).
